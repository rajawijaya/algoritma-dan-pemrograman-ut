## 🎯 Tujuan Pembelajaran

Melalui proyek ini, beberapa konsep dasar pemrograman yang dipelajari dan diimplementasikan meliputi:

- Penggunaan berbagai jenis operator dalam Java
  - Operator aritmatika
  - Operator perbandingan
  - Operator logika
- Penggunaan struktur percabangan (*if statement*)
- Pengolahan data menggunakan array
- Penerapan konsep modularity melalui pemecahan program ke dalam beberapa method atau fungsi
- Penyusunan kode yang lebih terstruktur dan mudah dipahami

---

## 🏗️ Implementasi Modularity

Pada proyek ini, konsep **modularity** diterapkan dengan memisahkan logika program ke dalam beberapa method yang memiliki tugas masing-masing.

Tujuan penerapan modularity:

- Membuat kode lebih rapi dan terorganisir
- Mengurangi duplikasi kode
- Mempermudah proses debugging
- Mempermudah pengembangan fitur baru
- Meningkatkan keterbacaan program

Dengan pendekatan ini, setiap bagian program memiliki tanggung jawab yang jelas sehingga lebih mudah dipelajari maupun dipelihara.

## 🚀 Cara Menjalankan Program

1. Clone repositori

```bash
git clone https://github.com/rajawijaya/algoritma-dan-pemrograman-ut.git
````

2. Masuk ke direktori proyek

```bash
cd algoritma-dan-pemorgaman-ut/src/
```

3. Compile program

```bash
javac Main.java
```

4. Jalankan program

```bash
java Main
```
